    Documentação — Landing Page de Pet Shop

Autor: Ricardo Werner Bruch
Cidade: Joinville - SC
Github: https://github.com/RicardoBruch (Projeto está lá como publico)

    Projeto desenvolvido em algumas etapas, separadas de acordo com a disponibilidade, onde foram feitas algumas partes em conjunto e indo lapidando conforme a necessidade, primeiramente feito um esqueleto de acordo com o que era necessário para o projeto, após a montagem do esqueleto, pego uma fonte já vista no projeto que foi a "POPPINS", onde foi visto na semana do desenvolvimento com o professor Nicholas.
    Inicialmente o projeto era diferente, onde tentei trazer outras idéias, porém acabou dificultando o processo juntamente as demandas do dia a dia, deixando assim o projeto um pouco mais simples e focando no que se pedia.
    Esqueleto montado, foi feito uma busca de imagens para aplicar, logo e nome da empresa foram utilizados a IA Gemini, muita dificuldade para deixar o fundo transparente tendo a necessidade de ir para o photoshop, outras imagens buscas simples no google, por ser algo simples não tive preocupações iniciais em questão de tamanho de imagens etc...
    Com tudo em mãos foi hora de ajustar cada parte em seu lugar, onde tive algumas dificuldades principalmente com a responsividade, recorrendo a alguns materiais extras para tentar atender a demanda.
